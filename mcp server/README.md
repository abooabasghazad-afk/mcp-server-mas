# Mastime MCP Server (mastime.ir)

یک سرور **MCP** کامل، جامع و دقیق برای سامانهٔ [mastime.ir](https://mastime.ir)
— «مــاس»، پلتفرم هوشمند مدیریت زمان و پخش سخنرانی.

این سرور، API پشتیبان واقعی سایت (که از باندل جاوااسکریپت برنامهٔ وب استخراج شده) را
به‌صورت ابزارهای **MCP** در معرض دستیارهای هوش مصنوعی قرار می‌دهد.

---

## امکانات

بیش از **۴۹ ابزار** در ۶ گروه:

| گروه | ابزارهای اصلی |
|------|----------------|
| **احراز هویت** | ورود، ثبت‌نام، دریافت پروفایل، تغییر رمز، بازیابی رمز با کد یک‌بارمصرف، تولید کد بازیابی، خروج |
| **اتاق‌ها** | لیست/ساخت/مشاهده/ویرایش/حذف/بازنشانی اتاق سخنرانی |
| **تایمر** | دریافت وضعیت زندهٔ تایمر و ارسال دستورها (شروع، توقف، ادامه، رفتن به نوبت، پایان، اضافه‌وقت، بازنشانی) |
| **سخنرانان** | افزودن، ویرایش، حذف (با حفظ/حذف ضبط)، جابه‌جایی نوبت‌ها، تعویض کد ورود، رفع فریز |
| **فایل‌ها و ضبط** | آپلود/دانلود/حذف/تأیید فایل، مدیریت جلسات ضبط صدا (شروع، ارسال قطعه، پایان) |
| **صفحهٔ عمومی** | وضعیت عمومی اتاق (با توکن اشتراک)، واکنش‌ها، گزارش PDF، پنل سخنران (ورود با کد، ضربان، خروج، فایل‌ها) |
| **مدیریت (ادمین)** | آمار کل، لیست کاربران، فعال/غیرفعال‌سازی کاربر، همهٔ اتاق‌ها، لاگ‌های حسابرسی |

اطلاعات دقیق اندپوینت‌ها، فیلدها و رفتارها مستقیماً از باندل JS تولیدی سایت
استخراج شده‌اند (نه حدس): از جمله فیلدهای فرم سخنران
(`gender`، `age`، `description`، `speaking_seconds`)، بدنهٔ دستورهای تایمر
(`action` / `speaker_id` / `expected_version`)، آپلود چندبخشی
(`upload_type=speaker|common`)، تأیید فایل (`{approved: bool}`) و
پارامتر `confirm_shrink` هنگام کوچک‌کردن ظرفیت.

## نصب

پیش‌نیاز: Python 3.10+

```bash
pip install -r requirements.txt
```

## اجرا

### از طریق stdio (پیش‌فرض — برای اتصال کلاینت‌های MCP)

```bash
python -m mastime_mcp.server
```

### از طریق HTTP (برای دیباگ یا کلاینت‌های HTTP)

```bash
python -m mastime_mcp.server --transport http --port 8000
```

### متغیرهای محیطی

| متغیر | توضیح | پیش‌فرض |
|--------|--------|----------|
| `MASTIME_API_BASE` | آدرس پایهٔ API | `https://mastime.ir` |

## اتصال به ZCode

فایل `mcp.json` را در ریشهٔ ورک‌اسپیس خود قرار دهید:

```json
{
  "mcpServers": {
    "mastime": {
      "command": "python",
      "args": ["-m", "mastime_mcp.server"],
      "cwd": "C:/Users/ASUS/Desktop/mcp server",
      "env": {}
    }
  }
}
```

> اگر `python` در مسیر نیست، مسیر کامل `python.exe` را در `command` بنویسید.

## جریان استفاده (برای عامل هوش مصنوعی)

1. **ورود یا ثبت‌نام**: ابتدا `mastime_login` (یا `mastime_register`) را صدا بزنید؛
   توکن نشست به‌صورت خودکار برای همهٔ ابزارهای مالک ذخیره می‌شود.
2. **اتاق**: `mastime_create_room` بسازید یا `mastime_list_rooms` بگیرید، سپس
   `mastime_get_room` برای جزئیات کامل (سخنرانان، فایل‌ها، تنظیمات).
3. **مدیریت جلسه**: با `mastime_add_speaker` سخنرانان را اضافه و با
   `mastime_timer_action` تایمر را کنترل کنید.
4. **صفحهٔ عمومی**: با توکن اشتراک اتاق (فیلد `public_token` در جزئیات اتاق)،
   `mastime_public_state` را بخوانید؛ سخنرانان با کد چهارکاراکتری از طریق
   `mastime_speaker_enter` وارد پنل می‌شوند.

**نکته دربارهٔ دو نشست:** توکن مالک (از `login/register`) و توکن سخنران
(از `speaker_enter`) مستقل‌اند؛ ابزارهای `speaker_*` از نشست سخنران استفاده
می‌کنند.

## آزمایش

```bash
python test_smoke.py
```

این تست سرور را از طریق پروتکل stdio بالا می‌آورد، ۴۹ ابزار را فهرست می‌کند
(بررسی وجود ابزارهای کلیدی)، و با یک تماس واقعی به `mastime.ir` صحت سیم‌کشی
HTTP را تأیید می‌کند (بدون ورود، باید پاسخ خطای ساخت‌یافتهٔ ۴۰۱ برگردد).

## ساختار پروژه

```
mcp server/
├── mastime_mcp/
│   ├── __init__.py      # متادیتای پکیج
│   ├── api.py           # کلاینت HTTP (MastimeClient) + نگاشت کامل اندپوینت‌ها
│   └── server.py        # تعریف FastMCP و همهٔ ابزارها
├── test_smoke.py        # تست دود
├── requirements.txt
├── mcp.json             # نمونهٔ پیکربندی برای کلاینت‌های MCP
└── README.md
```

## امنیت

- توکن‌های نشست فقط در حافظهٔ فرایند سرور نگهداری می‌شوند و روی دیسک نوشته نمی‌شوند.
- ابزارهای دانلود/آپلود فایل فقط با مسیر محلی کار می‌کنند.
- خطاهای API به‌صورت ساخت‌یافته (`{ok, status, error}`) برگردانده می‌شوند.
